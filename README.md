## Channel Emulator

The top-level module of the system is `ipm_ipMasterSoC_channelEmulator.v`. The paths to the project files are specified in `channelEmulator_files.csv`.

The Quartus Settings File (`ipm_ipMasterSoC_channelEmulator.qsf`) contains the project assignments, including the pin assignments required for FPGA implementation.

### Two-Port Master SoC Controller

The directory `ip_master_soc_controller/master_ce_2port/` contains an alternative implementation of the Master SoC Controller, configured with two AIP ports.

**Important considerations:**

1. **Project dependencies:** The dependencies required by the two-port Master SoC Controller have been added at the end of `channelEmulator_files.csv`. Make sure these entries are included when compiling the project in Quartus.

2. **Top-level module instantiation:** The two-port Master SoC Controller replaces the original 27-port implementation. Therefore, the instance in the top-level module must be updated accordingly. Replace the original instance with the following:

```verilog
ip_master_soc_controller_2p IPCORE_MASTER \
(
    .i_clk              ( clk               ),
    .i_rst_a            ( w_reset           ),
    .i_en_s             ( 1'b1              ),

    .i_data_in          ( w_DataMCUtoIP     ),
    .o_data_out         ( w_DataIPtoMCU     ),
    .i_write            ( w_WriteIP         ),
    .i_read             ( w_ReadIP          ),
    .i_start            ( w_StartIP         ),
    .i_conf_dbus        ( w_Conf            ),
    .o_int_req          ( w_INT             ),

    .i_int_ips          ( w_int             ),

    .o_dataInAIP_IP_s0  ( w_dataIn_s0       ),
    .i_dataOutAIP_IP_s0 ( w_dataOut_s0      ),
    .o_writeAIP_IP_s0   ( w_write_s0        ),
    .o_readAIP_IP_s0    ( w_read_s0         ),
    .o_start_IP_s0      ( w_start_s0        ),
    .o_configAIP_IP_s0  ( w_config_s0       ),

    .o_dataInAIP_IP_s1  ( w_dataIn_s1       ),
    .i_dataOutAIP_IP_s1 ( w_dataOut_s1      ),
    .o_writeAIP_IP_s1   ( w_write_s1        ),
    .o_readAIP_IP_s1    ( w_read_s1         ),
    .o_start_IP_s1      ( w_start_s1        ),
    .o_configAIP_IP_s1  ( w_config_s1       ),

    .o_gpio32           ( w_gpio32_o        )
);
```

**Note:** Make sure that the module identifier `ip_master_soc_controller_2p` matches the module declaration generated by Quartus for the two-port implementation.
